# Student Marks Management System

## Project Overview
A beginner-friendly Python project that manages student marks using dictionaries, functions, loops, and conditional statements.

The application calculates each student's total marks, average, and grade. It also identifies the highest-scoring and lowest-scoring students and generates an individual report for every student.

## Features
- Store student details and subject marks using nested dictionaries.
- Calculate total marks for each student.
- Calculate average marks.
- Assign grades based on average marks.
- Identify the topper.
- Identify the lowest scorer.
- Generate formatted student reports.
- Organize program execution using a `main()` function.

## Technologies Used
- Python 3
- Dictionaries and nested dictionaries
- For loops
- Conditional statements (`if`, `elif`, `else`)
- Functions
- Return statements
- Tuple unpacking
- String formatting
